# Signal Log

Running file maintained during Phase 2 Pass 1. Whenever a pattern becomes visible across two or more sources, it gets entered here. Rough working notes — patterns that recur and survive Pass 2 testing make it into dimension candidates; patterns that turn out to be single-source noise get dropped.

---

## How to use this file

Add entries as patterns surface during Pass 1 reading. Re-open and refine entries as more sources confirm or refute. In Pass 2, this file is one of the primary inputs to dimension candidate generation.

Do not refine entries to perfection during Pass 1. The signal log is observational, not analytical.
